# Synthetic document samples

These eight demonstrator documents use only `fixtures/synthetic-release.mjs`. They are **not official manufacturer window stickers**, do not identify real vehicles, and must not be used for operational or customer decisions.

Rebuild `samples.json` with `node scripts/build-demo-documents.mjs`. The HTML document has an exact fixture-identifier allowlist and uses escaped text. It does not accept arbitrary vehicle content or external document URLs.

`window-sticker-preview.png` is an AI-generated F-150 preview illustration, prominently labeled DEMO; it is not a captured source document. The readable HTML sample is authoritative for the synthetic figures. The image is used only for the F-150 demo, never other models.
